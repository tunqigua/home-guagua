# HOME

网站：[HOME](https://brain-room-cozy-1102.tunqigua.chatgpt.site/)。源码：[tunqigua/home-guagua](https://github.com/tunqigua/home-guagua)，私有仓库。最新首页与四语言验收见 `HOME-VERIFICATION.md`。

8 个小选择，找到你该住哪里。戴红围巾的像素小猫「挂挂」在暖窗旁陪伴，可以自由调整灯光、窗帘、三个窗台摆件和门牌话。

## 本地运行

```sh
python3 -m http.server 4173 --directory dist
```

打开 http://localhost:4173 。也可使用 Node.js 22+ 的 `npm run dev`、`npm test`、`npm run build`。不需要安装第三方运行依赖。`dist/` 是源码和静态产物，使用 hash 路由，支持根目录或子目录部署。

## 实现入口

- `dist/data.js`：八道题、固定类型映射、八类结果与三句门牌话。文案更新未改变旧计分映射。
- `dist/logic.js`：每次从完整答案重算最高分，并列选择最后出现的并列类型；严格校验场景、分享参数和存储数据。
- `dist/scene.js`：同一套像素 SVG 场景和挂挂，八种室内主题、灯光、窗帘与固定摆件位。页面和 PNG 使用相同场景配置与渲染函数。
- `dist/app.js`：200ms 点选反馈、自动前进、防连点、键盘确认、单一 60 秒毛球计时器、1.15 秒厚雪揭晓、装扮与分享后备。
- `dist/storage.js`：浏览器内会话状态、主动记住、旧答案迁移和本站键清理。
- `dist/card.js`：本地 Canvas 生成 1080 × 1440 PNG，像素场景关闭平滑、中文独立清晰排版。
- `dist/config.js`：作者赞赏码和更新说明配置。已接入作者提供的原图；关闭、缺少配置、非本站图片或加载失败时隐藏入口。

## 隐私与状态

答题草稿和本人结果默认在内存与 `sessionStorage` 的 `brain-room:v2:session` 保留；完成答题将草稿置空，不保留完整答案。仅主动勾选后，把房型、装扮与初始小物标识写入 `localStorage` 的 `brain-room:v2:remembered`。关闭勾选删除持久化记录。

旧 `brain-room:v1` 的答案在本地转换为临时草稿和最小结果，替代状态成功写入后才删除旧记录；若浏览器拒绝写入，保留旧记录防止丢失，并提示存储不可用。体验可在内存继续。清除只删除这三个本站键，两个存储域都会检查，不使用全站 storage.clear()。

分享 v2 的 hash 仅允许房型、灯光、窗帘、三个摆件与门牌标识，拒绝缺失、未知、重复参数。v1 房型链接继续可用。访客快照只在内存修改，不写入本人草稿或结果。原生分享取消静默返回；不支持时自动复制，复制失败提供手动文本。

应用没有答案/装扮/图片上传接口、外部字体、在线 AI、第三方统计或追踪。托管平台可能保留基础访问日志。清除本机记录不能撤回已下载图片或已发出的快照。

## 检查

`npm test` 含 65,536 组答案、旧样例、白名单、存储与迁移检查。`npm run build` 检查静态产物完整性和 JS 语法。

另运行 `python3 -m http.server 4174`，打开 http://localhost:4174/tests/runtime.html 执行真实浏览器运行验收，包含图片生成、网络请求监测、存储/系统分享/图片失败模拟。测试夹具不部署到 dist，也不使用生产站点存储。

详见 `VERIFICATION.md`。原站项目 ID 和地址保持不变，当前访问范围为 public。

## 自愿赞赏

入口位于完整结果、保存分享、装扮与结果说明之后。文案沿用作者提供的更新意愿，不展示创作工时、人数、金额或鸣谢名单。未实现好友留灯，不作承诺。

`dist/assets/appreciation-code.jpg` 是作者在本次对话提供的 IMG_6134.JPG，1152 × 1152，字节完全一致。弹层直接显示原图，支持查看原图、下载和系统原生长按。金额仅为文字参考，由访客在支付 App 自行填写。

赞赏码模式没有支付接口、回调或付款状态。打开、关闭、返回、等待和播放感谢都不记作打赏。感谢由每个人主动点“看看挂挂的感谢”播放，1.8 秒后定格，可跳过、返回及关闭；减少动态效果时直接显示静态捧杯挂挂。动画与场景共用同一只猫，未加入解锁项目或数据收集。

本地专项验收：打开 `http://localhost:4174/tests/support.html`。测试页面不在部署产物中。详见 `SUPPORT-VERIFICATION.md`。
